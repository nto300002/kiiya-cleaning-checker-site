# ホームと使い方ガイドの受け入れ

| 条件・操作 | 期待 | 確認 |
|---|---|---|
| ログイン済みの職員が各画面でヘッダーロゴを押す | 最初のホームへ戻り、再度作業に進める | 画面操作 |
| 未保存入力がある状態でロゴを押す | 保存成功後に移動。保存失敗・競合・画像処理中は移動せず入力を保持 | 自動テスト・画面 |
| 未確定の報告編集がある状態でロゴを押す | 移動確認を表示。キャンセルは編集を保持 | 画面 |
| ホームの「アプリの使い方」を押す | デモ画面のスクリーンショットを添えた4手順をモーダル表示。次へ・戻る・閉じる・Escapeで操作 | 自動テスト・画面 |
| 小画面・キーボードで利用 | スクロール・ボタン・画像が見え、操作できる | 画面 |

画像は個人情報を含まないデモSiteの画面例で、現行画面と一部異なることを表示する。Chatworkの送信元切り替えなど未実装の操作を説明しない。公開Siteでの送信や作業データの変更は行わない。

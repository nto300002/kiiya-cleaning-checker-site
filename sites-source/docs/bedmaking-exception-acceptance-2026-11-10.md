# ベッドメイク未実施・新規宿泊アメニティの受け入れ

対象：Site版25を基点とする新規実装。翌日への自動引き継ぎは承認待ちのため実装しない。セット場所の「要確認」は場所未確定の表示・チェックとし、実際の場所を推測しない。

| ケース | 条件・操作 | 期待結果・確認方法 |
| --- | --- | --- |
| B01 | 通常清掃を完了 | 従来の完了・保存・報告を維持、テストと画面確認 |
| B02 | 複数客室の一部を未実施、スタッフ不足・翌日対応 | 部屋別に記録、未実施と理由・対応を報告。翌日への自動引き継ぎなし |
| B03 | 未実施、その他 | 自由記述必須。未入力のまま報告不可 |
| B04 | 未実施、KIIYA依頼 | 満室は現場判断。依頼完了・自動送信と誤表示しない |
| B05 | 新規宿泊・アメニティのみ | 清掃・ベッドメイクを求めず、人数に応じた備品と設置場所「要確認」を表示 |
| B06 | 記録を再読込・変更・取消 | 作業・報告に内容を保持し、変更時に古い回答を流用しない |
| B07 | 旧記録・旧報告・不備・画像 | 欠損せず、既存の確定済み報告は変わらない |
| B08 | 直接APIで不正な理由・対応や入力欠落 | サーバーが拒否または報告を阻止 |

# 報告プレビューの編集確認

- 現場職員が自分の未確定の作業で報告画面を開き、プレビュー直下の「レポートを編集」を押すと、現在の本文を入力したモーダルが開く。固定フッターは変更しない。
- キャンセルではプレビューを変えず、変更を反映すると編集内容がプレビューに表示される。空欄は反映できない。編集は報告を確定するまで保存されない。
- 報告を確定すると、編集した本文が報告版に保存され、再表示・Markdown取得・配送用成果物に同じ本文が使われる。作業の更新番号が変わった場合は既存の競合検出で確定を拒否する。
- 報告プレビュー下の指定された未接続案内は表示しない。確定モーダル等の送信状態の説明は維持する。
- 確認方法: APIテストで空欄・上限超過の拒否、編集本文の保存と既存の権限制御を確認。ブラウザーでモーダルの反映・キャンセルと固定フッターを確認する。実配送は別の受け入れ条件で確認する。

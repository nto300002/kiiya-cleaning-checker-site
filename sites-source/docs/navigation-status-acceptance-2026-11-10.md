# ホームの日付とChatwork状態：ローカル受け入れ

- 過去記録を開いてロゴで戻ると、当日の日付を表示し、今日の作業は過去記録を開かない。過去の内容はアーカイブから再表示できる。
- 当日作業で入力中ならホーム遷移時に保存し、失敗・競合・画像送信中は移動や破棄をしない。日付をまたいだ場合も端末の下書きを消さない。
- 確認投稿の準備状態と業務報告の送信可否は区別し、連携画面の確認済みは送信先の確認結果と明記する。未取得や利用不能を成功と誤表示しない。
- 状態が変化したらホームに戻るたび読み直す。実際のChatwork投稿は行わない。ローカル画面と自動テストで検証し、公開しない。

## ローカル検証結果

- 合格：模擬APIの過去・当日記録で、アーカイブ→ホーム→今日の作業→当日の記録を自動操作し、日付と対象を確認。過去データへの書き込みなし（`test/home-navigation-status-ui.test.tsx`）。
- 合格：模擬APIで確認投稿の経路が稼働中・業務報告が準備中の組み合わせを表示。HTTPテストで正常・失効したワーカー監視を確認（`test/chatwork-production-http.test.ts`）。
- 合格：未保存の入力がある際、ロゴ操作で保存完了までホームに移動しない（`test/work-input-races.test.tsx`）。
- 未実施：本番データでの操作、実際のChatwork確認投稿・業務報告の送信、モバイル実機。ローカルのブラウザでアーカイブからの日付移動と接続済み状態を通した操作確認は未実施。

# 手動送信の受け入れ項目（2026-11-04）

既存の検証用接続を使い、個別の運用者操作を待たず現場職員が確認して送信する。本人・作業・候補・接続・職員版・設定版・配送主体と一意性をサーバー側で確認する。テストルーム固定は維持し、通常の実務向けルーム利用とは区別する。

- [ ] 有効な現場職員が自分の報告を固定し、送信先・本文・添付を確認し「確定して送信」で1回だけ配送する（自動・画面・実環境）。
- [ ] 参照権限のみ、別職員、古い版、未確認・変更された送信先、期限切れ・承認取消を拒否する（自動・API）。
- [ ] 同時操作、応答喪失と再読み込みで同じ試行に収束し、重複投稿しない（自動・API）。
- [ ] 確定前の閉じる操作では投稿しない。取得中の競合、準備失敗を安全に表示する（画面・自動）。
- [ ] 本文・Markdown・PDF・画像の部分失敗／結果不明を明示し、不明な試行を自動再送しない（既存・回帰）。
- [ ] 利用者が現在開いている作業・画像を変更せず、本人の手動テストに委ねる。実環境試験は専用の非機密データのみで確認。
- [ ] 実施日時、コミット、公開版、環境、テスト結果と未検証事項をIssue #12に記録する。
